## Step 0: Playwrightとは何か

### 0.1 概要

**Playwright**は、2020年にMicrosoftがリリースしたオープンソースのブラウザ自動化ライブラリです。元々GoogleでPuppeteerを開発していたチームがMicrosoftに移籍し、その経験を活かして一から設計・開発しました。

```
┌─────────────────────────────────────────────────────────────────────┐
│                     Playwright とは                                 │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  「プログラムからブラウザを完全に制御する」ためのライブラリ          │
│                                                                     │
│  ┌─────────────┐    ┌─────────────┐    ┌─────────────┐            │
│  │   あなたの   │    │  Playwright │    │  ブラウザ   │            │
│  │   Pythonコード│───▶│   (制御層)  │───▶│ Chromium等  │            │
│  └─────────────┘    └─────────────┘    └─────────────┘            │
│                                                                     │
│  人間がブラウザで行う全ての操作を、コードで自動実行できる            │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 0.2 Playwrightで何ができるのか

Playwrightは大きく分けて**3つの用途**で使用されます：

```
┌─────────────────────────────────────────────────────────────────────┐
│                    Playwright の3大用途                             │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  ┌───────────────────────────────────────────────────────────┐     │
│  │  1️⃣ Webスクレイピング / クローリング                        │     │
│  │     動的サイトからのデータ収集、JavaScript実行後の取得      │     │
│  └───────────────────────────────────────────────────────────┘     │
│                                                                     │
│  ┌───────────────────────────────────────────────────────────┐     │
│  │  2️⃣ E2E（End-to-End）テスト                                 │     │
│  │     Webアプリケーションの自動テスト、回帰テスト             │     │
│  └───────────────────────────────────────────────────────────┘     │
│                                                                     │
│  ┌───────────────────────────────────────────────────────────┐     │
│  │  3️⃣ ブラウザ操作の自動化（RPA的用途）                       │     │
│  │     定型業務の自動化、フォーム入力、レポート生成            │     │
│  └───────────────────────────────────────────────────────────┘     │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 0.3 なぜPlaywrightを使うのか

**Playwrightが特に強力な理由：JavaScript実行後のページを取得できる**

```
従来のスクレイピング（requests + BeautifulSoup）:
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│  requests.get(url) ──▶ サーバーから返されるHTML（生のHTML）        │
│                                                                     │
│  問題: JavaScriptで動的に生成されるコンテンツは取得できない！       │
│                                                                     │
│  例: SPAサイト、無限スクロール、Ajax読み込み、React/Vue/Angular    │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘

Playwrightによるスクレイピング:
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│  page.goto(url) ──▶ ブラウザがページを完全にレンダリング           │
│                  ──▶ JavaScript実行完了後のDOMを取得可能            │
│                                                                     │
│  解決: 人間がブラウザで見るのと同じ状態のページを取得できる！       │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

**具体例で理解しよう：**

```
あなたがAmazonで商品を検索する場面を想像してください。

1. 検索ボックスに「Python 本」と入力
2. 検索ボタンをクリック
3. 検索結果が表示される
4. 商品名と価格をメモする
5. 「次のページ」をクリック
6. 3-5を繰り返す

この作業、毎日やるのは大変ですよね？

Playwrightを使えば、この操作を全て自動化できます！
しかも、人間より高速に、24時間365日、ミスなく実行できます。
```

### 1.2 事前確認：Pythonはインストール済み？

まず、Pythonが使える状態か確認しましょう。

**ターミナル（コマンドプロンプト/PowerShell）で実行：**

```bash
python --version
```

**期待される出力：**
```
Python 3.9.7   # 3.8以上ならOK
```

> **💡 Pythonが入っていない場合**
> 
> [Python公式サイト](https://www.python.org/downloads/)からインストールしてください。
> Windows の場合は「Add Python to PATH」にチェックを入れてインストール！

### 1.3 仮想環境を作ろう（推奨）

プロジェクト専用の環境を作ることで、他のプロジェクトに影響を与えません。

```bash
# 作業フォルダを作成
mkdir playwright-tutorial
cd playwright-tutorial

# 仮想環境を作成
python -m venv venv
```

**仮想環境を有効化：**

```bash
# Windows（PowerShell）の場合
.\venv\Scripts\Activate.ps1

# Windows（コマンドプロンプト）の場合
.\venv\Scripts\activate.bat

# macOS / Linux の場合
source venv/bin/activate
```

**成功すると、プロンプトの先頭に `(venv)` が表示されます：**

```
(venv) C:\playwright-tutorial>
```

> **❓ なぜ仮想環境を使うの？**
> 
> Pythonのパッケージは、バージョンの違いで動かなくなることがあります。
> 仮想環境を使うと、プロジェクトごとに独立した環境を持てるので安心です。
> 
> 例：プロジェクトAではPlaywright 1.40、プロジェクトBでは1.35を使う、など

### 1.6 よくあるエラーと解決策

#### エラー①：`playwright : 用語 'playwright' は認識されていません`

**原因**: PATHが通っていない

**解決策**:
```bash
python -m playwright install
```

#### エラー②：`Permission denied` / `アクセスが拒否されました`

**原因**: 管理者権限が必要

**解決策（Windows）**:
- PowerShellを「管理者として実行」で開き直す

**解決策（macOS/Linux）**:
```bash
sudo playwright install
```

#### エラー③：SSL証明書エラー

**原因**: 企業のプロキシ環境

**解決策**: IT部門に相談するか、以下を試す
```bash
pip install playwright --trusted-host pypi.org --trusted-host files.pythonhosted.org
```

### 3.2 最小限のコード

まず、最もシンプルなコードから始めましょう。

```python
"""
Step 3: ブラウザを開いてみよう
ファイル名: step03_open_browser.py
"""

from playwright.sync_api import sync_playwright

# Playwrightを起動
with sync_playwright() as p:
    
    # ブラウザを起動（headless=Falseで画面表示）
    browser = p.chromium.launch(headless=False)
    
    # 新しいページ（タブ）を作成
    page = browser.new_page()
    
    # Webページにアクセス
    page.goto("https://example.com")
    
    # 3秒待機（ページを見る時間）
    page.wait_for_timeout(3000)
    
    # ブラウザを閉じる
    browser.close()

print("✅ ブラウザを開いて閉じました！")
```

### 3.3 実行してみよう

```bash
python step03_open_browser.py
```

**何が起きるか：**
1. Chromiumブラウザが自動で開く
2. example.com が表示される
3. 3秒後にブラウザが閉じる
4. ターミナルに「✅ ブラウザを開いて閉じました！」と表示される

### 3.4 コードを1行ずつ理解しよう

```python

"""
Step 4: ページのタイトルを取得しよう
ファイル名: step04_get_title.py
"""

from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch(headless=True)  # 画面なしで高速に
    page = browser.new_page()
    
    # いくつかのサイトを巡回してタイトルを取得
    urls = [
        "https://example.com",
        "https://www.google.com",
        "https://www.python.org",
    ]
    
    print("=" * 60)
    print("各サイトのタイトルを取得します")
    print("=" * 60)
    
    for url in urls:
        # ページにアクセス
        page.goto(url)
        
        # タイトルを取得
        title = page.title()
        
        # 現在のURLを取得（リダイレクトされている場合、元のURLと異なることがある）
        current_url = page.url
        
        # 結果を表示
        print(f"\n📄 URL: {current_url}")
        print(f"   タイトル: {title}")
    
    browser.close()

print("\n" + "=" * 60)
print("✅ 完了！")
```

### 6.2 要素を「特定する」とは？

### 6.3 コード

```python
"""
Step 6: ページ内のテキストを取得しよう
ファイル名: step06_get_text.py
"""

from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch(headless=True)
    page = browser.new_page()
    
    # example.com にアクセス
    page.goto("https://example.com")
    
    print("=" * 60)
    print("example.com からテキストを取得します")
    print("=" * 60)
    
    # 方法①: タグ名で要素を特定
    h1_text = page.locator("h1").text_content()
    print(f"\n【h1タグのテキスト】")
    print(f"   {h1_text}")
    
    # 方法②: 複数の段落（pタグ）がある場合、最初の1つを取得
    p_text = page.locator("p").first.text_content()
    print(f"\n【最初のpタグのテキスト】")
    print(f"   {p_text}")
    
    # 方法③: リンク（aタグ）のテキストを取得
    link_text = page.locator("a").text_content()
    print(f"\n【aタグ（リンク）のテキスト】")
    print(f"   {link_text}")
    
    # 方法④: リンクのhref属性（URL）を取得
    link_href = page.locator("a").get_attribute("href")
    print(f"\n【aタグのhref属性】")
    print(f"   {link_href}")
    
    browser.close()

print("\n✅ 完了！")
```

### 7.4 クリック対象の特定方法（4つの方法）

```python
# 方法①: テキストで指定（最も推奨！）
page.get_by_text("More information").click()

# 方法②: ロール（役割）で指定
page.get_by_role("link", name="More information").click()

# 方法③: CSSセレクターで指定
page.locator("a").click()

# 方法④: locator + filter で絞り込み
page.locator("a").filter(has_text="More").click()
```

### 7.5 get_by_〇〇 メソッド一覧

| メソッド | 説明 | 例 |
|---------|------|-----|
| `get_by_text()` | 表示テキストで検索 | `get_by_text("ログイン")` |
| `get_by_role()` | HTML要素の役割で検索 | `get_by_role("button")` |
| `get_by_label()` | ラベルで検索（フォーム用） | `get_by_label("メール")` |
| `get_by_placeholder()` | プレースホルダーで検索 | `get_by_placeholder("検索...")` |
| `get_by_test_id()` | data-testid属性で検索 | `get_by_test_id("submit-btn")` |

> **💡 なぜ get_by_text が推奨されるのか？**
> 
> - 人間が見ている「テキスト」で指定するので、直感的
> - HTMLの構造が変わっても、テキストが同じなら動く
> - コードを読んだ時に「何をクリックしているか」がすぐ分かる

```python
with sync_playwright() as p:
    browser = p.chromium.launch(headless=False)
    page = browser.new_page()
    
    # DuckDuckGo（プライバシー重視の検索エンジン）にアクセス
    # ※ Googleは構造が複雑なので、シンプルなDuckDuckGoで練習
    page.goto("https://duckduckgo.com")
    print("📄 DuckDuckGoにアクセスしました")
    
    # 検索キーワードを入力
    search_keyword = "Python Playwright"

    results = page.locator("[data-testid='result-title-a']").all()

    print("-" * 50)
    
    for i, result in enumerate(results[:5], 1):
        title = result.text_content()
        href = result.get_attribute("href")
        print(f"{i}. {title}")
        print(f"   URL: {href}")
        print()
    
    page.wait_for_timeout(3000)
    browser.close()

print("✅ 完了！")
```

```python
"""
Step 11: リンクを収集しよう
ファイル名: step11_collect_links.py
"""

from playwright.sync_api import sync_playwright
from urllib.parse import urljoin

with sync_playwright() as p:
    browser = p.chromium.launch(headless=True)
    page = browser.new_page()
    
    # 対象ページ
    target_url = "https://example.com"
    page.goto(target_url)
    print(f"📄 {target_url} にアクセスしました")
    
    # 全てのリンク（aタグ）を取得
    links = page.locator("a").all()
    print(f"📊 リンク数: {len(links)} 件")
    
    # リンク情報を収集
    link_data = []
    for link in links:
        text = link.text_content().strip()
        href = link.get_attribute("href")
        
        # href が None でなければリストに追加
        if href:
            # 相対URLを絶対URLに変換
            absolute_url = urljoin(target_url, href)
            link_data.append({
                "text": text,
                "url": absolute_url
            })
    
    # 結果を表示
    print("\n📋 収集したリンク:")
    print("-" * 60)
    for item in link_data:
        print(f"テキスト: {item['text']}")
        print(f"URL: {item['url']}")
        print()
    
    browser.close()

print("✅ 完了！")
```

```python
https://news.ycombinator.com/

import csv
from datetime import datetime
from playwright.sync_api import sync_playwright


def scrape_hackernews():
    """Hacker Newsから記事一覧を取得"""
    
    with sync_playwright() as p:
        browser = p.chromium.launch(headless=True)
        page = browser.new_page()
        
        print("🌐 Hacker News にアクセス中...")
        page.goto("https://news.ycombinator.com/")
        
        # 記事の行を取得
        articles = []
        rows = page.locator(".athing").all()
        
        print(f"📊 {len(rows)} 件の記事を発見")
        
        for row in rows:
            try:
                # 記事ID
                article_id = row.get_attribute("id")
                
                # タイトルとURL
                title_link = row.locator(".titleline > a").first
                title = title_link.text_content()
                url = title_link.get_attribute("href")
                
                # ポイント数（次の行にある）
                # IDを使って対応するスコア行を探す
                score_row = page.locator(f"#score_{article_id}")
                if score_row.count() > 0:
                    score = score_row.text_content()  # "123 points"
                else:
                    score = "0 points"
                
                articles.append({
                    "rank": len(articles) + 1,
                    "title": title,
                    "url": url,
                    "score": score,
                    "scraped_at": datetime.now().strftime("%Y-%m-%d %H:%M")
                })
                
            except Exception as e:
                print(f"   ⚠️ 記事のパース中にエラー: {e}")
                continue
        
        browser.close()
        return articles


def save_to_csv(articles, filename):
    """CSVファイルに保存"""
    with open(filename, "w", newline="", encoding="utf-8") as f:
        writer = csv.DictWriter(f, fieldnames=articles[0].keys())
        writer.writeheader()
        writer.writerows(articles)
    print(f"✅ {filename} に保存完了")


def main():
    print("=" * 60)
    print("🚀 Hacker News スクレイピング開始")
    print("=" * 60)
    
    # データ収集
    articles = scrape_hackernews()
    
    # ファイルに保存
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    filename = f"hackernews_{timestamp}.csv"
    save_to_csv(articles, filename)
    
    # 結果をプレビュー
    print(f"\n📋 取得した記事（上位10件）:")
    print("-" * 60)
    for article in articles[:10]:
        print(f"{article['rank']:2}. [{article['score']:>12}] {article['title'][:50]}")
    
    print("\n" + "=" * 60)
    print("🎉 完了！")
    print("=" * 60)


if __name__ == "__main__":
    main()
```

```python
"""
Step 14: 実践プロジェクト②：複数ページを巡回
ファイル名: step14_pagination.py

Hacker Newsの複数ページからデータを収集
"""

import csv
from datetime import datetime
from playwright.sync_api import sync_playwright


def scrape_multiple_pages(max_pages=3):
    """複数ページからデータを収集"""
    
    all_articles = []
    
    with sync_playwright() as p:
        browser = p.chromium.launch(headless=True)
        page = browser.new_page()
        
        # 最初のページにアクセス
        page.goto("https://news.ycombinator.com/")
        
        for page_num in range(1, max_pages + 1):
            print(f"\n📄 ページ {page_num} を処理中...")
            
            # 現在のページから記事を取得
            rows = page.locator(".athing").all()
            print(f"   → {len(rows)} 件の記事を発見")
            
            for row in rows:
                try:
                    article_id = row.get_attribute("id")
                    title_link = row.locator(".titleline > a").first
                    title = title_link.text_content()
                    url = title_link.get_attribute("href")
                    
                    all_articles.append({
                        "page": page_num,
                        "title": title,
                        "url": url,
                    })
                except Exception:
                    continue
            
            # 最後のページでなければ「More」をクリックして次のページへ
            if page_num < max_pages:
                more_link = page.locator("a.morelink")
                
                if more_link.count() > 0:
                    print(f"   → 次のページへ移動...")
                    more_link.click()
                    # ページの読み込みを待機
                    page.wait_for_load_state("networkidle")
                else:
                    print("   → これ以上ページがありません")
                    break
        
        browser.close()
    
    return all_articles


def main():
    print("=" * 60)
    print("🚀 複数ページ巡回スクレイピング")
    print("=" * 60)
    
    # 3ページ分のデータを収集
    articles = scrape_multiple_pages(max_pages=3)
    
    print(f"\n📊 合計 {len(articles)} 件の記事を収集しました")
    
    # CSVに保存
    filename = f"hackernews_multipage_{datetime.now():%Y%m%d_%H%M%S}.csv"
    with open(filename, "w", newline="", encoding="utf-8") as f:
        writer = csv.DictWriter(f, fieldnames=["page", "title", "url"])
        writer.writeheader()
        writer.writerows(articles)
    
    print(f"✅ {filename} に保存しました")
    
    # ページごとの集計
    print("\n📋 ページ別の記事数:")
    for page_num in range(1, 4):
        count = len([a for a in articles if a["page"] == page_num])
        print(f"   ページ {page_num}: {count} 件")
    
    print("\n🎉 完了！")


if __name__ == "__main__":
    main()
```

```python
    browser = p.chromium.launch(headless=True)
    page = browser.new_page()
    page.goto("https://example.com")
    # ... 処理 ...
    browser.close()


# ===== テキスト取得 =====
text = page.locator("h1").text_content()
texts = page.locator("li").all_text_contents()


# ===== 属性取得 =====
href = page.locator("a").get_attribute("href")
src = page.locator("img").get_attribute("src")


# ===== クリック =====
page.get_by_text("送信").click()
page.get_by_role("button", name="送信").click()


# ===== 入力 =====
page.get_by_placeholder("検索").fill("キーワード")
page.locator("[name='email']").fill("test@example.com")


# ===== キーボード =====
page.keyboard.press("Enter")
page.keyboard.press("Control+a")


# ===== 待機 =====
page.wait_for_selector(".loaded")
page.wait_for_load_state("networkidle")
page.wait_for_url("**/success")


# ===== スクリーンショット =====
page.screenshot(path="screenshot.png", full_page=True)


# ===== 複数要素 =====
elements = page.locator("li").all()
for el in elements:
    print(el.text_content())
```
